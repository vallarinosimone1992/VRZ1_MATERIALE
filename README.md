# VRZ1 Materiale

Webapp per la gestione e la ricerca del materiale disponibile nelle sedi scout di Ragioneria.

## Obiettivi della v1

- ricerca testuale del materiale;
- collocazione per branca, unità e (per E/G) squadriglia;
- stanza e posizione fisica opzionale;
- gestione quantità tramite operazioni **Consuma** e **Aggiungi**;
- note consultabili per ogni oggetto;
- log completo delle modifiche e dei movimenti;
- autenticazione e permessi differenziati per Admin, Capi, R/S ed E/G.

## Stack previsto

- React + TypeScript + Vite
- Supabase (PostgreSQL + Auth + Row Level Security)
- GitHub Pages per il frontend

## Stato

Progetto in fase di impostazione iniziale.
